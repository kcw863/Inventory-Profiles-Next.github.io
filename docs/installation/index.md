##教程

###1.安装mod加载程序

要运行此mod，您需要一个mod加载程序.有两个：[织物](https://fabricmc.net/)和[锻造](https://files.minecraftforge.net/net/minecraftforge/forge/). 

！！！提示“如果您不知道该选择哪种，我们推荐织物。"

==="结构"

    1.[下载结构(Universal/.JAR)](https://fabricmc.net/use/)
    2.启动
    3.选择你的我的世界版本
    4.单击“*安装*”

==="锻造"

    1.[下载锻造(推荐安装程序)](https://files.minecraftforge.net/net/minecraftforge/forge/)
    2.启动
    3、点击“确定”

###2.安装mod

==="结构"

    1.[下载结构API](https://www.curseforge.com/minecraft/mc-mods/fabric-api)
    2.[下载mod](../downloads/index.md)
    3.*(可选)*，要更轻松地访问mod设置，[下载mod菜单](https://www.curseforge.com/minecraft/mc-mods/modmenu)
    4.将它们放在".minecraft/mods"文件夹[^1]中

==="锻造"

    1.[下载mod](../downloads/index.md)
    2.将其放在".minecraft/mods"文件夹中[^1]

[^1]:

    ".minecraft"文件夹的默认位置如下：

    -**Windows**："%appdata%\.minecraft"，或"C：\Users\You\AppData\Roaming\.minecraft"
    -**Linux**：'~/.minecraft'
    -**MacOS**：‘~/Library/应用程序支持/我的世界'
